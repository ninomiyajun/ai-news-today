# 今日のニュースを情報源ごとの節に分けて表示する

## 目的

今日のニュースの記事一覧を、情報源（Hacker News と、はてなブックマーク）ごとの節に分けて表示する。

いまの一覧は、すべての記事を 1 つの列にまとめ、点数の高い順に並べている。ところが点数の意味は情報源によって違う
（Hacker News では投票の点数、はてなブックマークではブックマークの数）。そのため 1 つの列に混ぜると、比べられない数どうしで
順位が決まり、利用者は並び順から記事の注目の度合いを読み取れない。情報源ごとに節を分け、節の中だけで点数の高い順に
並べることで、同じ意味の点数どうしで記事を比べられるようにする。

## 利用者の操作の流れ

1. 利用者が今日のニュースの画面を開く。
2. 画面に、情報源ごとの節が、Hacker News の節、はてなブックマークの節の順に並ぶ。各節の見出しは「Hacker News（3 件）」
   「はてなブックマーク（1 件）」の形で、情報源の名前と、その節に表示している記事の件数を出す。
3. 各節の中には、その情報源の記事だけが、点数の高い順に並ぶ。点数が同じ記事は、公開日時の新しい順に並ぶ。記事ごとの
   表示は、いまの一覧と同じく、題のリンク、点数、記事に添えた X の投稿の埋め込みを出す。点数には情報源に合わせた単位を
   付ける（Hacker News は「412 点」、はてなブックマークは「156 ブックマーク」の形）。
4. 記事が 0 件の情報源の節は出さない（点数の下限で絞り込んだ結果の 0 件も含む）。すべての情報源が 0 件のときは、いまと
   同じ「表示できる記事はまだありません。」の 1 文だけを出す。

点数の下限の指定（画面の URL で 1 つの値を指定し、全記事に同じ下限を当てて「点数 N 以上を表示中」と出す）は、この仕様では
変えない。下限を節ごとにするかどうかは、別の仕様で決める。下限で絞り込んだときの節の見出しの件数は、絞り込んだ後に表示して
いる記事の数にする。
